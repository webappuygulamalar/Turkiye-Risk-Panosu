# Türkiye Risk Panosu

Türkiye ekonomisinde kriz riskini 0–100 arası tek puanla izleyen pano.

**Sayfa:** https://webappuygulamalar.github.io/Turkiye-Risk-Panosu/

Veriler TCMB, TÜİK, BDDK, Hazine ve Maliye Bakanlığı ve TBB'nin kamuya açık yayınlarından alınır. Modelin nasıl çalıştığı sayfadaki "Model nasıl çalışıyor?" butonunda anlatılır. Bilgilendirme amaçlıdır; yatırım tavsiyesi değildir.
